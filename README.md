# Segura — site de portfólio (loja de camisinhas)

Site estático (HTML, CSS e JS puro). O hero mostra um vídeo controlado pelo mouse: mouse para a direita avança, para a esquerda volta.

## Vídeo
Coloque um arquivo chamado `video.mp4` na mesma pasta do `index.html`. Sem ele, o site mostra camisinhas animadas em código.

## Publicar
GitHub Pages: Settings > Pages > Deploy from a branch > main / root.
